# 0.6.4 EPUB 排版调研

目标是让读者翻到任何一页，都能看出哪里是章题、引文、注释和正文，同时保留按书调节字体和字号的能力。前半部分记录改动前的表现与方案，文末记录 0.6.4 的实现和复验结果。

## 同一本书的基线

[原创对照样书](../tests/fixtures/typography-reference.epub) 只有一个正文章节，包含中英混排的正文、语义化大小标题、通过 CSS 类设置的眉题与副标题、脚注文字、诗行、代码、繁体中文与日文注音。随书只有一张 CSS 样式表，使用系统字体族。解压后可以直接查看 chapter.xhtml 和 style.css。

在 macOS Apple Books 打开该文件，当前窗口显示全书一页。其阅读界面将章题和小节识别为两个标题，正文、注释与日文读音均可读取。桌面截图未清楚呈现字形，Apple Books 的实际字体名称、字重和像素值仍待目视对照。下表记录的是同一份 EPUB 在 Chromium 中应用原书 CSS 后的计算样式，以及经改动前 DSH 插件解析、分页后的计算样式。字号按各自正文归一化，字族指 CSS 声明，实际绘制字形还取决于本机可用字体。

| 样书位置 | 原书样式 | DSH 0.6.4 基线 |
|---|---|---|
| FIELD NOTES 眉题 | 0.80 倍，无衬线，700，字距 0.15em | 1.00 倍，正文衬线栈，400，正常字距 |
| 章题 / 副标题 | 1.70 倍无衬线 700 / 1.15 倍无衬线 | 1.60 倍正文衬线栈 600 / 1.00 倍正文衬线栈 |
| 注释 | 0.80 倍，无衬线 | 1.00 倍，和正文同字族 |
| 两行诗 | 左缩进 2em，作者指定换行 | 换行保留，左缩进为 0 |
| pre 中的 code | 浏览器按原书排版时约为正文 0.81 倍 | 等宽仍在，pre 和 code 各缩一次，实际约 0.74 倍 |
| 章节语言 | XHTML 根元素为 zh-Hans，段落含 zh-Hant、ja | 章节根元素语言为空，带 lang 的子元素仍在 |

改动前的包解析只收集图像资源。章节渲染会重建 head 和 body，书内链接的 CSS、头部样式和根元素语言随之丢失。正文里的 class 还在，但已经没有对应的规则。插件提供的标题、图注和代码样式能识别语义标签，无法单靠 p 标签辨认作者用类标出的眉题、诗歌或注释。[章节与资源解析](../assets/epub.mjs) · [阅读器基础样式与分页](../client.js) · [现有字体设置与回退](../assets/reading-fonts.mjs)

### 复测计算样式

在本地测试页面打开样书并等待分页稳定，使用以下只读表达式记录元素的字号比例、字重和 CSS 字族。原书基准采用同一浏览器，在独立 iframe 加载该样书的 chapter.xhtml 与 style.css，将 doc 换成该 iframe 的 document。纸张颜色和显示器亮度不影响这些比值。

```js
const doc = document.querySelector('.bs-epub-frame').contentDocument
const style = id => doc.defaultView.getComputedStyle(doc.getElementById(id))
const base = parseFloat(style('body').fontSize)
console.table(['body', 'title', 'kicker', 'subtitle', 'note', 'poem', 'code'].map(id => {
  const css = style(id)
  return { id, scale: parseFloat(css.fontSize) / base, weight: css.fontWeight,
    family: css.fontFamily, indent: css.marginLeft, tracking: css.letterSpacing }
}))
```

## 可借鉴的 Apple Books 行为

Apple 的出版指南将正文 1em 作为便于缩放的基准，建议把特殊字族用在确有表达作用的地方。流式排版可使用设备字体和书内字体；符合其元数据约定的书，可在读者换字体后恢复原书字体。内嵌字族若需要真正的粗体，应提供相应字面。指南没有为所有书指定同一套标题和注释字号。[Apple 字体指南](https://help.apple.com/itc/booksassetguide/en.lproj/itc74d42b31e.html) · [Apple 字体最佳实践](https://help.apple.com/itc/booksassetguide/en.lproj/itcb303b7bb5.html)

EPUB Reading Systems 3.3 建议阅读器尊重作者样式的层叠，允许根据读者选择覆盖相关属性，并列出通过 @font-face 引用的字体格式。DSH 可以先实现用于流式排版的样式子集，单独记录暂未支持的书内资源。[W3C EPUB Reading Systems 3.3 §6.3](https://www.w3.org/TR/epub-rs-33/#sec-css)

## 建议的实现顺序

1. **先恢复书籍已经表达的差异。** 在 EPUB 清单中索引本书的 CSS，按章节相对路径读取 link 和 style，保留原有顺序、可接受的选择器以及字号、字族、字重、字形、行距、缩进、字距等排版属性。样书的眉题使用 font 简写，需要通过 CSS 解析展开后逐项筛选。章节根节点从 XHTML 的 lang 或 xml:lang 继承语言，缺省时回退到包元数据。可见页和后台计页 iframe 应使用完全相同的结果。继续限制资源为书内路径，复用现有隔离阅读框。
2. **明确原书与读者的控制范围。** 初始采用原书样式；书中未指定的段落继承阅读器基础字体。保留已有的单书和全局字体选择，显式自选字体作用于正文；标题、重点、注释与代码继续体现相对字号及字形差异。提供恢复原书排版的入口。夜间模式和阅读器高亮保有可读的前景、背景和选区对比。
3. **再补无样式书籍。** 正文以 1em 为基准，区分 h1–h3、strong、em、blockquote、figcaption、语义化脚注和 code。代码块只缩放一次。中、繁、日分别验证可用字体和注音，缺字体时沿现有设备回退栈显示；诗歌保持作者硬换行。普通 p 元素保持正文待遇，避免把普通短句猜成副标题。
4. **单独评估内嵌字体。** 区分常规、粗体和斜体字面，按清单和 @font-face 关联；字体加载后重新计页并保留同一文字锚点。使用可再分发字体验证成功、缺字面和加载失败三条路径。固定版式、竖排与字体混淆需各自专门样书，不能从这一页推定兼容程度。

## 验收方案

| 操作 | 通过标准 |
|---|---|
| 在 Apple Books 和 DSH 打开样书，固定窗口尺寸，选择原书排版 | 对照章题、眉题、副标题、诗行、注释和代码。DSH 中原书定义的字号比例、粗细、字距和缩进可测，两个标题仍具有标题语义。记录主题、字号、窗口宽高和页数，跨引擎分页允许不同。 |
| 在 DSH 调大字号、切换自选字体、恢复原书设置 | 正文及标题注释随字号放大，粗体、英文斜体、代码等宽与日文注音仍可辨；恢复后原书层级重现。 |
| 在浅色、深色、单页、自适应跨页下分别翻页 | 注释可读，代码行和注音不裁切；同一配置的可见页与后台计页一致。字体加载或改变字号后，原段落仍可见。 |
| 在切换前添加书签和高亮，切换后关闭再打开 | 原记录保留，已标文本仍对应原句。另用长章测量增量解析与重排时间，并分开记录已有的标注列表跳章首问题。 |
| 用缺少样式表、缺字面和完全无样式的书打开同一组语义元素 | 段落可读，标题和正文仍可区分，页面完成分页；无书外字体或样式请求。 |

## 0.6.4 实施与同书复验

DSH 现按章节顺序使用包内样式表、章节 style 和元素的行内排版。首次阅读默认使用原书字体，已有全局或单书字体选择继续生效，可在阅读设置中选择「原书字体」恢复。分页尺寸、主题色与高亮仍由阅读器管理。本轮覆盖流式 EPUB 的本机字体、字号层级、语言和段落排版。内嵌字体、固定版式、竖排和复杂条件样式仍需专门样书。

在同一份《纸上声音 · 排版对照》上，以正文为 1，DSH 章题为 **1.70**、副标题 **1.15**、注释 **0.80**，眉题为 **0.80 / 700**。在正文 19px 时，诗行左缩进 38px，眉题字距 2.28px。代码只缩放一次，约为正文的 0.86 倍。原书模式的正文字族为 Songti SC、serif，标题与注释使用样书指定的无衬线。章节保留 zh-Hans，正文保留繁体段落和日文注音。

桌面 DSH 在样书的原书字体、14 号字时显示 1 / 1。高亮引文里的「回声」并添加书签后，调至 22 号字、切换系统无衬线，页数变为 2。翻到末页，返回书架选择「暂不标记」，再打开恢复到 2 / 2、100%。书签和高亮各一条，点击「回声」回到原句所在的第 1 页。样书已保留在本机书架。

Apple Books 使用「原始」主题，同一文件原窗口为 1 页，其辅助功能界面分别识别一级章题、二级小节、引文、注释及日文注音。桌面捕获可见主题和页码，但未呈现可辨认的正文字形。上面的比例来自原始 EPUB 与 DSH 的计算样式，未测得 Apple Books 的像素值。

浏览器回归使用同一 EPUB，分别在原书 19px、等宽 20px、恢复原书 20px 下比较可见页和后台计页框的实际样式。另用长章验证跨章选择下划线后，原文字范围出现在当前视口；用只有一页的末章分别检查已读比例和恢复位置。
